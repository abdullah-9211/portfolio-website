## 4. Design direction (already prototyped)

A first version was built as a single-file Claude artifact and the "systems log / documentation" direction was explicitly rejected as too plain. A second, much more editorial "immersive experience" version was built and well-received in review — **use that as the creative direction**, adapted to a real multi-page/multi-component site.

### 4.1 Creative concept
An immersive, dark, kinetic personal site — not a resume-in-cards. Big typography carries the personality. A signature visual motif: an **animated node/graph network** in the hero (and reused as ambient texture elsewhere), representing data/access-control graphs — deliberately tied to Abdullah's actual specialty (data access governance) rather than generic decoration. Mouse-reactive: nodes drift and connect with faint lines, occasional bright "pulses" travel between nearby nodes like an access grant/data packet.

### 4.2 Design tokens used
**Color (dark, committed — no light mode, this was an intentional single-theme choice):**
```
--bg:        #07080A   (near-black, cool undertone)
--bg-2:      #0D0F12   (slightly raised panel)
--ink:       #F2F4F3   (primary text, near-white)
--ink-soft:  #9CA3A6   (secondary text)
--ink-faint: #565D60   (tertiary/meta text)
--line:      #1D2125   (hairline borders)
--grad-a:    #4F7DF3   (blue)
--grad-b:    #A85DE8   (violet)
--grad-c:    #E85DBE   (magenta)   ← signature 3-stop gradient, echoes Valkrix's own brand gradient
--status:    #5FBF77   (semantic green, used sparingly for "active/current" indicators only)
```
**Venture-specific fixed micro-palettes** (kept constant regardless of theme, like embedded brand plaques):
- Valkrix card: near-black bg (`#020203`), line `#1C1C22`, uses the same blue→violet→magenta gradient for its wordmark
- Forge card: dark wood gradient (`#241A10` → `#2E2013`), line `#3C2C19`, gold accent `#C9A227`

**Typography:**
- Display: **Bricolage Grotesque** (Google Fonts, variable weight 400–800) — huge, expressive, used for the name and big headings
- Accent/italic: **Instrument Serif** italic — used sparingly for single emphasized words inline (e.g. "Building *both*, on purpose.")
- Body: **Archivo** — clean workhorse sans, avoid over-relying on Inter/Space Grotesk (flagged as generic/AI-cliché choices)
- Mono/labels/data: **JetBrains Mono** — used for eyebrows, timestamps, tags, nav

### 4.4 Interaction/motion notes
- Hero elements do a brief, orchestrated staggered fade/rise-in on page load only (not scroll-triggered) — content must never be stuck at `opacity:0` waiting on a scroll observer; everything should be visible at rest even without JS.
- Respect `prefers-reduced-motion: reduce` throughout — freeze the canvas animation (still show a static graph), disable pulses, disable marquee scroll (fall back to a wrapped static row), disable pulse/status-dot animations.
- Grain/noise texture overlay at very low opacity for tactility (optional polish).
- Magnetic tilt on the two venture cards only (mousemove-driven rotateX/rotateY), desktop/fine-pointer only.
